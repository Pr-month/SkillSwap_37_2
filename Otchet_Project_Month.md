## Краткое описание задач

**Issue #5 — Подключить JwtModule в app.module глобально**
Подключен `JwtModule` в `AppModule` с флагом `global: true`. Настроены переменные окружения `JWT_SECRET` и время жизни токена. Установлена зависимость `@nestjs/jwt`.

**Issue #10 — Регистрация пользователя (POST /auth/register)**
Реализован эндпоинт регистрации. Добавлена валидация входных данных (`class-validator`), проверка уникальности email, хеширование пароля (`bcrypt`) и генерация пары токенов (access/refresh).

**Issue #6 — Подключить пайпу валидации в main.ts**
В `src/main.ts` подключен глобальный `ValidationPipe` с настройками `whitelist: true` (удаляет лишние поля) и `transform: true` (преобразует типы).

**Issue #11 — Вход в аккаунт (POST /auth/login)**
Реализован эндпоинт аутентификации. Настроена проверка валидности email и пароля, выдача JWT токенов при успешном входе. Обработаны ошибки авторизации (`UnauthorizedException`).

**Issue #16 — Получение списка пользователей (GET /users)**
Реализован эндпоинт получения всех пользователей. Настроена фильтрация данных: в ответе возвращаются только публичные поля (без паролей). Написаны тесты.

**Issue #12 — Стратегия и гарда для защиты по Access токену**
Реализованы `JwtAccessStrategy` и `JwtAccessGuard` на базе `passport-jwt`. Стратегия извлекает токен из заголовка `Authorization: Bearer` и валидирует его.

**Issue #13 — Стратегия и гарда для Refresh токена**
Реализованы `JwtRefreshStrategy` и `JwtRefreshGuard`. Стратегия используется для защищенных маршрутов обновления токенов.

**Issue #17 — Получение профиля текущего пользователя (GET /users/me)**
Реализован эндпоинт `GET /users/me`, защищенный `JwtAccessGuard`. Эндпоинт возвращает данные текущего авторизованного пользователя на основе токена. Проведен рефакторинг типов (`TAuthRequest`).
